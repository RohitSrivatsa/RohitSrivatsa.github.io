# rohitsrivatsa.github.io

Rohit Srivatsa's portfolio, live at https://rohitsrivatsa.github.io

A static site with no build step: `index.html`, `site.css`, and three scripts (`deck.js` for navigation and themes, `sky.js` for the animated sky, `projects.js` for the project dashboards). The chart data is in `data/`; every number comes from the project repositories or public BTS data.
